Melon

Drag, scroll or use arrow keys to move around!

Melon generates cool terrain
which users can scroll in!

It also allows you to place
things like this anywhere in it

To use, copy the below code into the header;

These scripts are minified for your convenience!

Each element directly under the body tag will be placed in the world.
Without anything else, everything will be placed at (0,0).
Add data-pos="x y" to set the position of the element (in hexagons)

Additionally, data-min="x y" and data-max="x y" can be added
to the body tag to define the minimum and maximum positions
the centre of the camera can reach (in hexagons).

Use the class allowclick
to allow clicking as well as dragging!
