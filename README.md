# Melon
Melon is a script for creating cool webpages you can move around in with a background of generated terrain!

This repo comes with an example that also explains how to use it.

## Building
To build the website you will need `minify` installed, then run `./build.sh`.

All the files in `base/` and `src/` get compiled into `index.html`, `style.css` and `main.js` in the project's directory
